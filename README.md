🌱 Agro Forte, Futuro Sustentável

Uma landing page educativa desenvolvida para o Projeto Agrinho, com o objetivo de apresentar a importância do agronegócio sustentável, mostrando como tecnologia, inovação e preservação ambiental podem caminhar juntas para garantir um futuro melhor.

---

## 📖 Sobre o Projeto

O projeto “Agro Forte, Futuro Sustentável” foi criado para conscientizar sobre a importância da sustentabilidade no campo, destacando práticas agrícolas responsáveis, uso inteligente da tecnologia e preservação dos recursos naturais.

A proposta do site é oferecer uma experiência visual moderna, educativa e interativa para estudantes, professores e visitantes.

---

## 🎯 Objetivo

- Incentivar a conscientização ambiental 🌍
- Mostrar a importância do agronegócio sustentável 🌱
- Apresentar tecnologias utilizadas no campo 🚜
- Desenvolver conhecimentos em programação e design 💻
- Criar uma experiência interativa e acessível ✨

---
