# AgroTec Sustentável 🌾🛰️

O **AgroTec Sustentável** é um projeto tecnológico desenvolvido especialmente para o **Concurso Agrinho 2026**. O objetivo principal do site é apresentar soluções inovadoras e automatizadas para o campo, focando na otimização de recursos e na redução de desperdícios na agricultura e pecuária.

---

## 🚀 Funcionalidades do Site

* **Apresentação do Projeto:** Detalhes sobre a iniciativa e o impacto da tecnologia no ecossistema rural.
* **Comedouro Inteligente:** Explicação técnica sobre o funcionamento do protótipo automatizado de alimentação animal.
* **Simulador Interativo:** Ferramenta em JavaScript que calcula a estimativa de economia de água e ração com base nos dias de uso do sistema.
* **Design Responsivo:** Interface adaptada para visualização em computadores, tablets e smartphones.
